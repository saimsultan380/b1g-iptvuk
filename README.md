# b1g-iptvuk

B1G Player marketing site for [b1giptvplayers.com](https://b1giptvplayers.com).

This repository is independent of other B1G sites. Do not push to `b1g-sec-red` or point this Vercel project at `b1gplayer.uk`.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production canonical host: `https://b1giptvplayers.com`
